The root `vault` package defines the `Config` struct, `DefaultConfig()` defaults, and the `Option` functions you pass to `vault.New`. You need a store and nothing else; every other option has a default.

```go
v, err := vault.New(
    vault.WithStore(memory.New()),
    vault.WithAppID("myapp"),
)
```

## vault.Config

`Config` holds the configuration for a Vault instance.

```go
import "github.com/xraph/vault"

type Config struct {
    // AppID is the application identifier used for scoping secrets, flags, and config.
    AppID string `json:"app_id" yaml:"app_id"`

    // EncryptionKey is the master encryption key (32 bytes for AES-256-GCM).
    // It wins over EncryptionKeyEnv when both are set.
    EncryptionKey []byte `json:"-" yaml:"-"`

    // EncryptionKeyEnv names an environment variable that holds the key.
    // It's read only when EncryptionKey is empty, and New fails if the
    // variable is unset, empty or can't be decoded.
    EncryptionKeyEnv string `json:"encryption_key_env" yaml:"encryption_key_env"`

    // FlagCacheTTL is the TTL for the flag evaluation cache.
    // Defaults to 30 seconds.
    FlagCacheTTL time.Duration `json:"flag_cache_ttl" yaml:"flag_cache_ttl"`

    // SourcePollInterval is the interval for polling database sources.
    // Defaults to 30 seconds.
    SourcePollInterval time.Duration `json:"source_poll_interval" yaml:"source_poll_interval"`
}
```

### Field reference

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `AppID` | `string` | `""` | Application identifier used for scoping all entities. |
| `EncryptionKey` | `[]byte` | `nil` | 32-byte AES-256-GCM master key. Wins over `EncryptionKeyEnv`. Excluded from JSON/YAML serialization. |
| `EncryptionKeyEnv` | `string` | `""` | Environment variable that holds the key, read when `EncryptionKey` is empty. `New` fails if you name it and it's unset, empty or undecodable. |
| `FlagCacheTTL` | `time.Duration` | `30s` | TTL for the flag evaluation cache. |
| `SourcePollInterval` | `time.Duration` | `30s` | Interval for polling database configuration sources. |

### DefaultConfig

`DefaultConfig()` returns a `Config` with sensible defaults:

```go
cfg := vault.DefaultConfig()
// cfg.FlagCacheTTL = 30 * time.Second
// cfg.SourcePollInterval = 30 * time.Second
```

## Option functions

`Option` is a function type that configures a `Vault` instance. You pass options to `vault.New`, which applies them in order.

```go
type Option func(*Vault)
```

### Available options

| Option | Signature | Description |
|--------|-----------|-------------|
| `WithStore` | `WithStore(s store.Store) Option` | Sets the store backend. Required: `New` returns `ErrNoStore` without one. |
| `WithAppID` | `WithAppID(appID string) Option` | Sets the application identifier used for scoping. |
| `WithEncryptionKey` | `WithEncryptionKey(key []byte) Option` | Sets the 32-byte AES-256-GCM master encryption key. |
| `WithEncryptionKeyEnv` | `WithEncryptionKeyEnv(envVar string) Option` | Sets the environment variable name for the encryption key. |
| `WithLogger` | `WithLogger(l log.Logger) Option` | Sets the structured logger (`github.com/xraph/go-utils/log`) for internal events. |
| `WithConfig` | `WithConfig(cfg Config) Option` | Overlays `cfg` onto the current configuration. Non-zero fields override; zero fields leave what earlier options set. |

### Usage

```go
import (
    "github.com/xraph/vault"
    "github.com/xraph/vault/store/memory"
)

v, err := vault.New(
    vault.WithStore(memory.New()),
    vault.WithAppID("myapp"),
    vault.WithEncryptionKey([]byte("my-32-byte-secret-key-for-vault!")),
)
if err != nil {
    return err
}
```

`New` picks the key like this:

1. If you set `EncryptionKey`, that's the key. `EncryptionKeyEnv` is ignored.
2. Otherwise, if you name a variable with `EncryptionKeyEnv`, that variable must hold a valid key. `New` won't quietly carry on without one.
3. Only when you configure neither does vault store secrets unencrypted. `New` logs a warning through your logger when that happens, so you'll want a key in anything past local development.

`New` fails when:

- you leave out the store (`ErrNoStore`);
- you give it a key that isn't a valid 32-byte key;
- you name a variable with `EncryptionKeyEnv` and it's unset, empty or can't be decoded. Naming the variable tells vault you expect encryption, so it refuses to start rather than write plaintext you think is encrypted.

### Combining WithConfig with other options

`WithConfig` copies only the non-zero fields of the `Config` you give it. A field you leave at its zero value keeps whatever an earlier option or `DefaultConfig()` set, so you can put `WithConfig` before or after `WithAppID` and `WithEncryptionKey` and both still hold:

```go
v, err := vault.New(
    vault.WithStore(s),
    vault.WithEncryptionKey(key),
    vault.WithConfig(vault.Config{FlagCacheTTL: time.Minute}), // key is kept
)
```

This also means `WithConfig` can't clear a field. Passing an empty `AppID` leaves the current one in place.

### Loading the encryption key from an environment variable

If you'd rather not put the key in code, use `WithEncryptionKeyEnv` to name an environment variable. `New` reads it only when `EncryptionKey` is empty, and fails if the variable is unset, empty or can't be decoded. You can read the same variable yourself with `crypto.EnvKeyProvider`:

```go
import "github.com/xraph/vault/crypto"

// Set the env var name on the config.
vault.WithEncryptionKeyEnv("VAULT_ENCRYPTION_KEY")

// At runtime, read the key.
provider := crypto.NewEnvKeyProvider("VAULT_ENCRYPTION_KEY")
key, err := provider.GetKey(ctx)
```

The provider auto-detects hex encoding (64 characters = 32 bytes) and base64 encoding (standard, URL-safe, or raw/no-padding).

## The store

`WithStore` takes a `store.Store` from `github.com/xraph/vault/store`. It composes every subsystem's store interface, and `vault.New` hands that one store to all six services:

```go
type Store interface {
    secret.Store
    flag.Store
    config.Store
    override.Store
    rotation.Store
    audit.Store

    Migrate(ctx context.Context) error
    Ping(ctx context.Context) error
    Close() error
}
```

The `memory`, `postgres`, `sqlite` and `mongo` backends all implement it. `v.Store()` gives you back the store you passed in, and `v.Health(ctx)` pings it.

## Per-service configuration

`vault.New` builds every service below for you. You only need these option functions if you're composing the services yourself without `New`. They're independent of the root `vault.Option` functions.

### secret.ServiceOption

```go
import "github.com/xraph/vault/secret"

svc := secret.NewService(store, enc,
    secret.WithAppID("myapp"),
    secret.WithOnAccess(func(ctx context.Context, key, appID string) {
        // called after every Get/GetVersion
    }),
    secret.WithOnMutate(func(ctx context.Context, action, key, appID string) {
        // called after every Set/Delete
    }),
)
```

### flag.EngineOption

```go
import "github.com/xraph/vault/flag"

engine := flag.NewEngine(store,
    flag.WithCacheTTL(30 * time.Second),
)
```

### flag.ServiceOption

```go
flagSvc := flag.NewService(engine,
    flag.WithAppID("myapp"),
)
```

### config.ServiceOption

```go
import "github.com/xraph/vault/config"

configSvc := config.NewService(store,
    config.WithAppID("myapp"),
    config.WithResolver(resolver),
)
```

### override.ResolverOption

```go
import "github.com/xraph/vault/override"

resolver := override.NewResolver(configStore, overrideStore,
    override.WithCacheTTL(30 * time.Second),
    override.WithLogger(slog.Default()),
)
```

### rotation.ManagerOption

```go
import "github.com/xraph/vault/rotation"

mgr := rotation.NewManager(store, secretSvc,
    rotation.WithAppID("myapp"),
    rotation.WithCheckInterval(1 * time.Minute),
    rotation.WithLogger(slog.Default()),
)
```

### audit.LoggerOption

```go
import "github.com/xraph/vault/audit"

logger := audit.NewLogger(store,
    audit.WithHook(auditHookExtension),
    audit.WithLogger(slog.Default()),
)
```
