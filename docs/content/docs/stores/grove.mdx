---
title: Grove Integration
description: How Vault's database stores sit on Grove.
---

Vault's PostgreSQL, SQLite and MongoDB stores are all built on [Grove](https://github.com/xraph/grove): each one takes a `*grove.DB` opened with the matching Grove driver. There is no separate `store/grovestore` package. This page covers what the three have in common; each store's own page has the details.

| Store | Package | Grove driver |
|-------|---------|--------------|
| [PostgreSQL](/docs/stores/postgres) | `store/postgres` | `pgdriver` |
| [SQLite](/docs/stores/sqlite) | `store/sqlite` | `sqlitedriver` |
| [MongoDB](/docs/stores/mongo) | `store/mongo` | `mongodriver` |

## Constructor pattern

```go
// Open a driver, then wrap it in a grove.DB.
drv := pgdriver.New()
if err := drv.Open(ctx, dsn); err != nil {
    log.Fatal(err)
}
db, err := grove.Open(drv)
if err != nil {
    log.Fatal(err)
}

s := postgres.New(db) // or sqlite.New(db), mongo.New(db)
if err := s.Migrate(ctx); err != nil {
    log.Fatal(err)
}
```

Every constructor has the shape `New(db *grove.DB, opts ...StoreOption) *Store`, and each package has a `WithLogger(l log.Logger)` option taking a `github.com/xraph/go-utils/log` logger.

## Migrations

Each package exports a Grove migration group, `Migrations`, named `"vault"`, and each store's `Migrate` method creates what that backend needs:

- PostgreSQL runs idempotent DDL statements directly.
- SQLite runs its migration group through Grove's migrator, so import `github.com/xraph/grove/drivers/sqlitedriver/sqlitemigrate` for its side effect.
- MongoDB builds its indexes, which creates any collection that doesn't exist yet.

## Auto-detection with Forge

Under the Forge extension you don't build the store yourself. The extension resolves a `*grove.DB` from the DI container (the one named by `WithGroveDatabase` or `grove_database`, else the default) and picks the store from the driver name:

| Grove driver | Store |
|--------------|-------|
| `pg` | `store/postgres` |
| `sqlite` | `store/sqlite` |
| `mongo` | `store/mongo` |

The extension never calls `Migrate`, though. Run it once yourself before the first start; see [Forge extension](/docs/guides/forge-extension#migrations).
