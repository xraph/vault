---
title: PostgreSQL Store
description: PostgreSQL backend on Grove with pgdriver.
---

The PostgreSQL store (`store/postgres`) is the recommended backend for production. It runs on a [Grove](https://github.com/xraph/grove) `*grove.DB` opened with Grove's `pgdriver`, and `Migrate` creates its tables with plain DDL statements compiled into the package.

## Creating a store

```go
import (
    "github.com/xraph/grove"
    "github.com/xraph/grove/drivers/pgdriver"
    "github.com/xraph/vault/store/postgres"
)

drv := pgdriver.New()
if err := drv.Open(ctx, "postgres://user:pass@localhost:5432/vault?sslmode=disable"); err != nil {
    log.Fatal(err)
}
db, err := grove.Open(drv)
if err != nil {
    log.Fatal(err)
}

s := postgres.New(db)
defer s.Close()

if err := s.Migrate(ctx); err != nil {
    log.Fatal(err)
}
```

Under Forge, you don't build it yourself: the extension builds it from the `*grove.DB` the Grove extension registered. But the extension never calls `Migrate`, so run it once yourself before the first start (see [Forge extension](/docs/guides/forge-extension#migrations)).

## Options

| Option | Signature | Description |
|--------|-----------|-------------|
| `WithLogger` | `WithLogger(l log.Logger) StoreOption` | A `github.com/xraph/go-utils/log` logger for migration progress. Defaults to a no-op logger. |

## Migrations

`Migrate` executes `CREATE TABLE IF NOT EXISTS` statements for every table, then the column additions and indexes that came later (`ADD COLUMN IF NOT EXISTS`, `CREATE INDEX IF NOT EXISTS`), then the statements that scope secrets by tenant. Every statement is idempotent, so it's safe to call on every startup. There's no migration tracking table.

The same steps are also registered as a Grove migration group, `postgres.Migrations`, if you'd rather run them through Grove's migrator.

## Tables

The store creates 11 tables across secrets, flags, config, overrides, rotation, and audit:

| Table | Entity |
|-------|--------|
| `vault_secrets` | `secret.Secret` |
| `vault_secret_versions` | `secret.Version` |
| `vault_flags` | `flag.Definition` |
| `vault_flag_rules` | `flag.Rule` |
| `vault_flag_overrides` | `flag.TenantOverride` |
| `vault_config` | `config.Entry` |
| `vault_config_versions` | `config.EntryVersion` |
| `vault_overrides` | `override.Override` |
| `vault_rotation_policies` | `rotation.Policy` |
| `vault_rotation_records` | `rotation.Record` |
| `vault_audit` | `audit.Entry` |

## Lifecycle methods

| Method | Behaviour |
|--------|-----------|
| `Migrate(ctx)` | Creates all tables and indexes, idempotently |
| `Ping(ctx)` | Verifies connectivity through the Grove DB |
| `Close()` | Closes the Grove DB |

## When to use

- Production deployments that need durable storage.
- Several application instances sharing one database.
- Teams already running PostgreSQL.

## Complete example

```go
package main

import (
    "context"
    "fmt"
    "log"
    "os"

    "github.com/xraph/grove"
    "github.com/xraph/grove/drivers/pgdriver"
    "github.com/xraph/vault"
    "github.com/xraph/vault/scope"
    "github.com/xraph/vault/store/postgres"
)

func main() {
    ctx := context.Background()

    dsn := os.Getenv("DATABASE_URL")
    if dsn == "" {
        dsn = "postgres://localhost:5432/vault?sslmode=disable"
    }

    drv := pgdriver.New()
    if err := drv.Open(ctx, dsn); err != nil {
        log.Fatal("connect: ", err)
    }
    db, err := grove.Open(drv)
    if err != nil {
        log.Fatal("grove: ", err)
    }

    store := postgres.New(db)
    defer store.Close()

    // Idempotent: safe to call on every startup.
    if err := store.Migrate(ctx); err != nil {
        log.Fatal("migrate: ", err)
    }

    v, err := vault.New(
        vault.WithStore(store),
        vault.WithAppID("myapp"),
        vault.WithEncryptionKeyEnv("VAULT_ENCRYPTION_KEY"), // 32 bytes, hex or base64
    )
    if err != nil {
        log.Fatal(err)
    }

    ctx = scope.WithScope(ctx, "myapp", "acme", "", "")

    meta, err := v.Secrets().Set(ctx, "api_key", []byte("sk-live-abc123"), "")
    if err != nil {
        log.Fatal(err)
    }
    fmt.Printf("Secret stored: key=%s version=%d\n", meta.Key, meta.Version)

    if err := v.Config().Set(ctx, "max_retries", 3, ""); err != nil {
        log.Fatal(err)
    }
    fmt.Printf("Max retries: %d\n", v.Config().Int(ctx, "max_retries", 1))
}
```
